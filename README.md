# Simple reactive todo

### Setup

Clone the repo
```sh
git clone https://github.com/brainiacs-rw/alu-brainiacs-simple-reactivee-todo-app
```

Open the dir
```sh
cd alu-brainiacs-simple-reactivee-todo-app
```

Install packages
```sh
npm i -g pnpm && pnpm install
```

Run the app
```sh
pnpm run dev
```
